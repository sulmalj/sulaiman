## تدريب 3.5.1 — البيانات: 2, 5, 3, 4, 6, 4, 5, 3, 4
- x̄ = Σxi / n = 36 / 9 = **4**
- x̂ = **4**
- S² = Σ(xi − x̄)² / (n − 1) = 12 / 8 = 1.5 ، S = √1.5 = **1.22**
- SKp = (x̄ − x̂) / S = (4 − 4) / 1.22 = **0** ← **متماثل**

## تدريب 3.5.2 — البيانات: 4, 3, 6, 4, 2, 5, 6, 3
